## AI 辅助实现与修正

- 实现 `src/main.py` 中的检索、原文读取和结束工具；真实模式通过兼容聊天补全的 `tool_calls` 接口，让模型在观察工具结果后继续选择动作。
- 实现独立的确定性 Mock 模式，用于无密钥环境下检查工具接线、状态和引用约束。Mock 的动作选择不能证明真实模型具有相同决策能力。
- 增加回答前的程序校验：引用必须逐字对应已读取原文；同主题的已检索候选未读完时，不允许直接给出单一答案；已读规则冲突时，不允许直接给出单一答案。
- 首次测试发现资料外问题误命中输入包装文字，随后修正 Mock 检索输入；生成示例时又修正了 Windows 子进程输出编码问题。之后重新生成了示例和测试记录。

## 实际验证及边界

本地使用 Python 3.12.9，在 Mock 模式下执行六套输入，生成的实际输出与逐步 Trace 位于 `examples/*.output.json`。`examples/test-results.txt` 记录了六套命令退出码均为 0，以及 11 项单元测试全部通过。测试覆盖明确答案、文档冲突、资料外问题、改写相似问题、上下文追问、工具失败、替换资料后的结果变化、步数上限、伪造引用拦截及模型工具调用报文格式。

没有提供真实模型 API 密钥，因此**未执行真实模型调用**，也未验证真实模型在六类场景中的动作选择和回答质量。接口报文格式测试使用模拟响应，不等于真实模型测试。当前结果只证明离线流程和程序约束在这些用例下有效。
