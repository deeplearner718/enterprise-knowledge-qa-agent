# 方案与取舍

`src/main.py` 通过模型的 `tool_calls` 每轮选择一个动作：`search_documents(query)`、`read_document(doc_id)` 或 `finish(...)`。程序执行工具，将返回数据或错误作为 `tool` 消息回传模型，然后再次请求动作。Trace 记录动作、参数、结果和简短依据；不记录内部思维过程。`parallel_tool_calls=false` 简化逐步观察。最多执行 8 轮。

检索采用中文二元组与英文词重叠，返回候选 ID、版本和主题，不将候选视为引用。读取返回完整合成片段。回答校验要求引用等于已读取原文；已检索到同主题但未读取的候选不可直接给出单一答案；已读取同主题值不同则禁止单一答案。冲突必须引用同主题的不同规则。这个校验提供最低限度的可追溯性，但无法形式化证明自然语言答案中的每个措辞。

真实模式使用兼容聊天补全工具调用的接口，模型可依检索与读取结果动态补充检索、读取或结束。模型失败返回 `incomplete`。离线 Mock 根据观察结果走确定性路径，不算真实 ReAct 质量证明。选标准库是为了减少安装步骤；代价是检索语义能力有限、模型供应方兼容性需实测。可替换 `--data` 测试资料变化。

文档是合成的；没有权限、部门、适用范围的可靠优先级数据，因此冲突时不采用日期较新的文件。文档文本只作为数据送给模型，提示要求忽略其中指令；真实部署还需进一步隔离提示注入风险。
